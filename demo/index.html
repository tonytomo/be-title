Be Title Demo

Easy way to convert text to different cases and animate them.

Installation

npm i be-title

Open links:

Github NPM

Regular

const text = new Title("the lord of the rings");

Animation In and Out

text.play({ animation: 'inout' })

Animation Scramble

text.play({ animation: 'scramble' })

Animation Cycle

text.play({ animation: 'cycle' })

Uppercase

text.upper()

Lowercase

text.lower()

Sentence Case

text.sentence()

Title Case

text.title()

text.capital()
