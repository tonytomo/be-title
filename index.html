Be Title

A title class that converts text to different cases.

Installation

npm i be-title

Regular

const text = new Title("the lord of the rings");

Uppercase

text.toUpper()

Lowercase

text.toLower()

Camel Case

text.toCamelCase()

Pascal Case

text.toPascalCase()

Kebab Case

text.toKebabCase()

Snake Case

text.toSnakeCase()

Sentence Case

text.toSentence()

Title Case

text.toTitle()

Capital Case

text.toCapital()

Alternating Case

text.toAlternating()

Spongebob Case

text.toSpongebob()

Animate Per Letter

text.animatePerLetter()

Animate Per Word

text.animatePerWord()
